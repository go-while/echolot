On Thu, 10 Mar 2016 10:47:24 -0600, Anonymous wrote in
Message-Id: <nbs8eu$mh$1@news.mixmin.net>:

>   Since I had success install echolot in user pinger before, I am 
> returning to that route and try to find a way for echolot to execute 
> mixmaster from the different user mix.

This will probably cause you loads of problems as Echolot needs to write
files into the ~/Mix directory.  If you split them under different user
accounts, things will get complicated.  Maybe try going through things
one step at a time.

First of all, I'd suggest creating a global procmailrc file as
/etc/procmailrc.  There are a number of settings you probably want to be
common across all your user accounts and you can handle the exceptions
(like echolot) later.

/etc/procmailrc:
#!/bin/bash

SHELL=/bin/bash
DROPPRIVS=yes
PMDIR=$HOME/procmail
DATE=`date +%Y%m%d`
MAILDIR=${HOME}/Maildir/
ORGMAIL=$MAILDIR
DEFAULT=$ORGMAIL

You might want to add some other settings in there later but that's a
good foundation to build on.  Your mail will now be delivered to each
user account in Maildir format.

Now create your account for Echolot (doesn't matter what name you give
it).

Login as that user and create the basic Maildir folders:
mkdir -p ~/Maildir/{cur,new,tmp}

Create a procmail log directory:
mkdir ~/procmail

Create a procmailrc for this user:
~/.procmailrc:
LOGFILE=$PMDIR/$DATE
VERBOSE=no

This will log each delivery from procmail to that user's Maildir in a
file called ~/procmail/20160310 (or whatever the date is)

Now send the user a test message.  If all goes well, it will arrive in
~/Maildir/new/

You can also check your procmail logfile for any messages.

Once that's sorted, install Mixmaster using your Echolot user account.
Stick with the defaults and install it to ~/Mix.

Now untar echolot-2.1.9 and then rename the directory to echolot:
mv ~/echolot-2.1.9 ~/echolot

Edit your previously created ~/.procmailrc file and add the following:
#Default Recipe for Echolot
:0
$HOME/echolot/mail/

Make sure you leave a blank line between these new lines and the
existing lines.  As in:

LOGFILE=$PMDIR/$DATE
VERBOSE=no

#Default Recipe for Echolot
:0
$HOME/echolot/mail/

Send your Echolot user another email.  If all goes well, the mail will
now arrive in ~/echolot/mail/new/.  If so, great, you've overridden the
default mail location with the one Echolot wants.

Now you can configure Echolot's pingd.conf file.
Also edit the ~/echolot/tools/pingctl file and change the following two
entries to match your configuration:
USER=echolot
BASEDIR="/home/echolot/echolot"

Now you're ready to go and you can start Echolot with the command:
~/echolot/tools/pingctl start

Watch the pingd.log for any messages.

Finally, add some remailers to your pinger.
