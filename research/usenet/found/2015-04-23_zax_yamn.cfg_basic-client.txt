Yamn includes a DNS resolver.  By default it attempts to send your mail
directly to the mailserver (MX) of the first hop in the chain.  In this
instance, it failed.  It could be that your ISP blocks outbound mail on
port 25 or maybe a network glitch.

If you persistently see these messages, you might need to create a
yamn.cfg file and tell it your mail setup.

Here is a basic cfg file that might help:

[Mail]
SMTPRelay = "smtp.yourisp.net"
SMTPPort = 587
Username = "your smtp userid"
Password = "your smtp password"
UseTLS = true
MXRelay = false

If your ISP's smtp doesn't support TLS, you might need to change
"UseTLS" to false.  MXRelay defaults to true.  This overrides the other
settings and tells Yamn to use the recipient's SMTP server.
